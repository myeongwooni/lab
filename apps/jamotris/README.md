# 자모트리스

떨어지는 자모를 쌓아 글자를, 글자를 이어 단어를 만드는 한글 테트리스입니다.

- 조각은 자음(민트)과 모음(분홍) 한 칸씩 떨어지고, 바로 아래 칸과 합쳐질 수 있으면 합쳐집니다
  - 자음 위에 모음 → 글자 (ㄱ + ㅏ → 가), 모음 위에 자음 → 글자 (ㅗ + ㄱ → 고)
  - 받침 없는 글자 위에 자음 → 받침 (가 + ㅁ → 감)
  - 모음 위에 모음 → 겹모음 (고 + ㅏ → 과)
- 글자가 가로(왼쪽→오른쪽)나 세로(위→아래)로 사전에 있는 단어가 되면 사라지고, 칸이 꽉 찬 줄도 사라집니다
- 지운 뒤 떨어진 글자로 또 단어가 되면 연쇄 배수가 붙습니다
- 조각은 단어 하나를 떨굴 순서대로 풀어 내보내고, 가끔 아무 자모가 끼어듭니다
- 최고 점수와 만든 단어(단어장)는 브라우저 `localStorage`에만 남습니다. 로그인과 서버 저장 없음

| 조작 | 키보드 | 화면 |
| --- | --- | --- |
| 옮기기 | ← → | ◀ ▶, 또는 옮길 칸 누르기 |
| 한 칸 내리기 | ↓ | ▼ |
| 떨구기 | 스페이스, ↑ | 떨구기 |
| 보관 | C, Shift | 바꾸기 |
| 멈춤 | P, Esc | — |

단어 목록은 `app/hangul.ts`의 `RAW_WORDS`에 있습니다. 된소리나 겹받침처럼 조각으로 만들 수 없는
글자가 든 단어는 불러올 때 알아서 빠집니다.

## 로컬 실행

```bash
npm install
npm run jamotris
```

환경변수는 필요하지 않습니다.
