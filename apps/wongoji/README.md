# 이어달리기 원고지

한 사람이 하루에 한 글자씩, 모두가 이어 쓰는 원고지. 다음 글자가 무엇이 될지는 누구도 정할 수
없고, 한 번 쓴 글자는 지워지지 않습니다. 200칸이 차면 다음 장으로 넘어갑니다.

## 규칙이 코드에서 어떻게 지켜지나

- **하루 한 글자** — 방문자마다 `wongoji:turn:<날짜>:<id>` 키를 `SET NX EX`로 잡습니다.
  성공한 요청만 글자를 씁니다. 동시에 두 번 눌러도 하나만 통과하고, TTL이 KST 자정에 맞춰져 있어
  따로 초기화 작업이 필요 없습니다.
- **글자는 append-only** — `RPUSH` 하나로 끝나므로 순서가 꼬이거나 덮어써질 일이 없습니다.
- **신원** — 로그인이 없습니다. 1년짜리 httpOnly 쿠키가 방문자를 구분하고, 쿠키를 지우고 다시
  오는 경우를 대비해 IP 해시에 하루 8회의 느슨한 상한을 둡니다. 한국 모바일 網은 다수가 한
  주소를 공유하므로 IP는 주된 제한이 아니라 보조 장치입니다.
- **이름** — 쿠키에서 유도한 해시로 `말없는 사슴` 같은 별명을 만들어 쓴 시점에 함께 저장합니다.

## 로컬에서 실행

```bash
npm install          # 저장소 루트에서
npm run wongoji
```

환경변수 없이도 뜹니다. 이때는 메모리 폴백이라 서버를 다시 켜면 원고지가 비워집니다.
실제 데이터를 쓰려면 `.env.example`을 `.env.local`로 복사하고 Upstash 값을 채우세요.

## 배포

Vercel 프로젝트를 만들 때 Root Directory를 `apps/wongoji`로 지정하고,
Storage 탭에서 Upstash Redis를 연결하면 두 환경변수가 자동으로 주입됩니다.
