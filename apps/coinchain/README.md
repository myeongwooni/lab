# 동전 체인

모두가 이어 온 하나의 연속 기록. 동전을 던져 앞면이 나오면 체인이 1 늘어나고,
200번에 한 번 뒷면이 나오면 체인은 0으로 돌아갑니다. 끊은 사람의 이름과 그때의 숫자는
지워지지 않습니다.

## 왜 200분의 1인가

체인 게임의 성패는 확률 하나로 갈립니다. 흔히 떠올리는 50%로 하면 체인의 기대 길이가
2 언저리라 기록이라는 게 성립하지 않습니다. 200분의 1이면 기대 길이가 200 근처가 되어
체인이 수백까지 자라고, 그래서 끊는 일이 사건이 됩니다. 값은 `lib/store.ts`의
`BREAK_ODDS` 하나로 조절합니다.

## 동시성

- **체인 연장** — `INCR`. 동시에 던진 사람들이 각자 자기 몫의 링크를 얻습니다.
- **체인 절단** — `GETSET chain 0`. 뒷면이 동시에 두 번 나와도 앞선 호출만 0이 아닌 값을
  받으므로, 같은 붕괴가 두 번 기록되지 않습니다.
- **쿨다운** — 방문자마다 `SET NX EX 30`. 통과한 요청만 동전을 던집니다.

## 로컬에서 실행

```bash
npm install          # 저장소 루트에서
npm run coinchain    # http://localhost:3001
```

환경변수 없이도 뜹니다. 이때는 메모리 폴백이라 서버를 다시 켜면 기록이 초기화됩니다.

## 배포

Vercel 프로젝트를 만들 때 Root Directory를 `apps/coinchain`으로 지정하고,
Storage 탭에서 Upstash Redis를 연결하면 두 환경변수가 자동으로 주입됩니다.
키에 `coin:` 접두어가 붙으므로 다른 앱과 같은 Upstash 인스턴스를 공유해도 충돌하지 않습니다.
