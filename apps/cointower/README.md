# 동전탑

버튼을 한 번 누르면 앞면이 나오는 동안 동전이 저절로 계속 던져집니다. 뒷면이 나오는 순간
탑이 무너지고, 그때까지 쌓은 층수가 기록판에 남습니다. 확률은 정확히 반반입니다.

## 판정은 서버가 한 번에 한다

클라이언트가 한 번에 한 번씩 던지게 두면 기록판이 조작에 그대로 열립니다. 그래서 서버가
`randomInt(2)`로 뒷면이 나올 때까지 돌려 **연속 횟수 하나만** 내려주고, 화면은 그 숫자를
애니메이션으로 재생만 합니다. 콘솔에서 점수를 만들어 낼 방법이 없습니다.

`RUN_CAP`은 게임 규칙이 아니라 무한 루프 방지용입니다. 80에 닿을 확률은 2^-80입니다.

## 기록

- 사람당 한 줄입니다. `ZADD ... GT`로 최고 기록만 남기므로, 나중에 나온 낮은 기록이
  이전 기록을 끌어내리지 않습니다.
- 개인 최고는 같은 ZSET의 `ZSCORE`로 읽습니다. 별도 키가 없습니다.

## 도전 횟수

제한이 없습니다. 다만 스크립트가 엔드포인트를 연타해 Redis 명령 한도를 태우는 것만
막으려고 방문자당 1초 간격(`SPAM_FLOOR_SEC`)을 둡니다. 동전 애니메이션이 그보다 길어서
사람은 체감하지 못합니다. 빼려면 `takeSlot` 호출 한 줄을 지우면 됩니다.

## 확률 감각

반반이므로 n층에 닿을 확률은 2^-n입니다.

| 층 | 확률 | 한 번 보려면 |
| --- | --- | --- |
| 5 | 1/32 | 32번 |
| 10 | 1/1,024 | 천 번 |
| 15 | 1/32,768 | 삼만 번 |
| 20 | 1/1,048,576 | 백만 번 |

## 로컬에서 실행

```bash
npm install          # 저장소 루트에서
npm run cointower    # http://localhost:3001
```

환경변수 없이도 뜹니다. 이때는 메모리 폴백이라 서버를 다시 켜면 기록이 초기화됩니다.

## 배포

Vercel 프로젝트를 만들 때 Root Directory를 `apps/cointower`로 지정하고,
Storage 탭에서 Upstash Redis를 연결하면 두 환경변수가 자동으로 주입됩니다.
키에 `tower:` 접두어가 붙으므로 다른 앱과 같은 Upstash 인스턴스를 공유해도 충돌하지 않습니다.
