# 이름을 잃은 별에게

*To a Star That Lost Its Name* — 판타지 로맨스 비주얼 노벨입니다.

> 백 일 뒤 지워야 할 남자의 일생을 받아 적던 필경사는, 그 책의 마지막 장에 자기 이름이 적혀 있다는 걸 알게 된다.

사람이 태어나 이름이 천명록에 적히면 하늘의 고리 천환에 그 사람의 별이 켜지는 세계입니다. 성서관의 젊은
필경사 에스텔은 태어날 때부터 별이 없습니다. 어느 날 천명록이 그녀를, 망각형을 선고받은 흑기사 카시안 아르덴의
집필자로 지목합니다. 백 일 동안 그의 일생을 한 권의 망각서로 적고, 백 일째 밤 그 책과 함께 그의 이름을 태우는 일입니다.

## 구성

- 프롤로그와 공통 루트 5장, 그 뒤로 세 갈래
  - **카시안 루트** 3장 — 굿 엔딩 「이름을 부르는 사람」, 노멀 엔딩 「별이 된 기사」
  - **루시엔 루트** 3장 — 굿 엔딩 「다시 쓰는 첫 줄」, 배드 엔딩 「빈 페이지」
  - **진실 루트** 4장 — 트루 엔딩 「이름을 잃은 별에게」. 카시안·루시엔 루트의 엔딩을 하나씩 본 뒤 5장 마지막 갈림길에 열립니다
- 공통 루트 중간의 배드 엔딩 「충실한 필경사」까지 엔딩 여섯 개
- 선택지가 두 사람의 호감도와 플래그를 움직이고, 루트의 끝은 그것으로 갈립니다
- 장마다 편지 한 통으로 시작합니다. 받은 편지는 편지함에 모입니다

## 기능

- 대사창(ADV)과 소설식 전면 화면(NVL), 한 글자씩 풀리는 문장, 루비(윗글자)
- 자동 진행, 읽은 문장 넘기기(Ctrl), 대사 기록, 창 숨기기, 번호 키로 선택지 고르기
- 저장 슬롯 18개와 자동·빠른 기록. 선택지·장 전환·탭 닫기 때마다 자동 기록
- 회상록(이벤트 그림과 엔딩 도감), 음악실, 편지함, 장 고르기
- 글자 속도·자동 대기·글자 크기·음량 설정
- 모든 기록은 브라우저 `localStorage`에 남습니다. 로그인과 서버 저장은 없습니다

## 모든 것을 코드로

외부 이미지나 오디오 파일이 없습니다.

- **그림**: 배경 30장, 이벤트 그림 19장, 인물 10명(표정 10종)이 전부 코드로 그린 SVG입니다 — `app/art/`
- **음악**: 배경음악 14곡, 환경음 6종, 효과음 21종을 Web Audio API로 그 자리에서 합성합니다 — `app/audio/`
- **입자**: 눈, 비, 꽃잎, 유성, 등불, 떠다니는 글자는 캔버스로 그립니다 — `app/ui/Particles.tsx`

## 원고

`app/story/<장>.ts`에 장마다 한 편씩 있습니다. 한 줄이 클릭 한 번이고, `@`로 시작하는 줄이 연출 명령입니다.

- 세계관·인물·줄거리·변수 표: [`docs/bible.md`](docs/bible.md)
- 원고 규격과 문체 가이드: [`docs/script-spec.md`](docs/script-spec.md)
- 아트 디렉션: [`docs/art-direction.md`](docs/art-direction.md)

원고를 고친 뒤에는 두 가지로 확인합니다.

```bash
cd apps/starscribe
node scripts/check-story.ts                                   # 규격 위반, 없는 id·라벨, 오타 난 변수
node --import ./scripts/ts-resolve.mjs scripts/playtest.ts   # 무작위로 수백 번 끝까지 읽어 막다른 길 찾기
```

## 로컬 실행

```bash
npm install
npm run starscribe   # :3006
```

환경변수는 필요하지 않습니다.
