# 스크립트 규격 (StarScript) + 문체 가이드

게임 원고는 `apps/starscribe/app/story/<id>.ts` 파일 하나에 한 장(章)씩 쓴다. 파일 형식:

```ts
// 제1장 「별 없는 필경사」
export default String.raw`
* ch01
@bgm archive
...
`;
```

- 반드시 `String.raw` 템플릿 문자열. 본문에 백틱(`)과 `${`를 쓰지 말 것.
- 파일의 첫 라벨은 장 id와 같다 (`* ch01`).
- 장의 끝은 `@next <다음 장 id>` 또는 `@end <엔딩 id>` 또는 분기(`@choice`)로 끝난다. 흐름이 끊긴 채 끝나면 안 된다.

## 1. 한 줄 = 한 명령

빈 줄은 무시. `//`로 시작하는 줄은 주석.

### 텍스트 줄 (클릭 한 번에 한 줄)
| 형식 | 의미 |
|---|---|
| `그냥 문장.` | 서술(에스텔의 1인칭). 이름표 없음. |
| `카시안: 대사` | 대사. 화면에 “ ”가 자동으로 붙으니 **따옴표를 쓰지 말 것.** |
| `카시안[smile]: 대사` | 대사 + 그 인물 스탠딩의 표정을 바꿈(표정 목록은 아래). |
| `에스텔: 대사` | 주인공의 말. |
| `???: 대사` | 정체 불명의 화자. |
| `간수: 대사` | 스탠딩이 없는 단역도 이름만 쓰면 된다. |
| `(카시안): 속삭임` | 괄호 이름 = 작은 목소리/멀리서 들리는 소리. 이탤릭 처리. |

- 서술 줄에 `짧은말: 내용`처럼 앞쪽 12자 안에 쌍점(:)을 쓰면 대사로 읽힌다. 서술에는 쌍점을 쓰지 말 것.
- 한 줄은 **한국어 기준 대략 120자 이하** (ADV 대사창 3줄 분량). 긴 서술은 여러 줄로 나눈다.
- 인라인 표기:
  - `[천환|天環]` → 루비(윗글자). 한 장에 새 용어가 처음 나올 때만 쓴다. 남발 금지.
  - `*강조*` → 강조(은빛 글씨).
  - `{w}` → 타자 중간에 잠깐 멈춤(말줄임의 호흡). 한 줄에 1~2개까지.
  - `──` 는 그대로 표시된다(지워진 이름 연출에 사용).

### 무대 명령
| 명령 | 의미 |
|---|---|
| `@bg <배경id> [전환] [ms]` | 배경 교체. 전환: `cross`(기본) `fade`(검은색 경유) `white`(흰색 경유) `cut`(즉시) `ink`(먹이 번지듯) |
| `@cg <cgid>` / `@cg off` | 이벤트 CG 표시(갤러리 해금) / 닫기. CG가 떠 있는 동안 스탠딩은 가려진다. |
| `@show <인물id> [표정] [위치]` | 스탠딩 등장/갱신. 위치: `left` `center` `right` (기본 center) |
| `@hide <인물id>` / `@hide all` | 스탠딩 퇴장 |
| `@bgm <곡id> [ms]` / `@bgm stop [ms]` | 배경음악(교차 페이드) |
| `@amb <환경음id>` / `@amb none` | 환경음 루프 |
| `@se <효과음id>` | 효과음 |
| `@fx <입자id>` / `@fx none` | 화면 입자 효과 |
| `@filter <필터id>` / `@filter none` | 화면 색조. `memory`(회상, 바랜 빛) `night`(푸른 밤) `dark`(어둡게) `blur`(흐림) `warm`(따뜻하게) |
| `@shake` / `@shake big` | 화면 흔들림 |
| `@flash` / `@flash red` / `@flash gold` | 번쩍임(기본 흰색) |
| `@wait <ms>` | 멈춤 |
| `@title <작은글>|<큰글>` | 장 제목 카드. 예: `@title 제1장|별 없는 필경사` |
| `@day <n>` | "백일서 · 제 n일" 날짜 카드 |
| `@place <장소 이름>` | 장소 자막(좌상단에 잠깐). 예: `@place 루멘하임 · 성서관 대열람실` |
| `@letter <머리글>` … `@endletter` | 편지 카드. 사이의 줄은 `|`로 시작. 한 `|`줄이 편지의 한 문단. 예시는 아래 |
| `@nvl` / `@adv` | NVL 모드(화면 전체에 문장이 쌓이는 소설식) / 일반 대사창 모드 |
| `@clear` | NVL 화면 비우기(쪽 넘김) |
| `@set <변수> <값>` / `@add <변수> <n>` / `@flag <이름>` | 변수 조작. `@add c 1`, `@flag lullaby` |
| `@if <조건> -> <라벨>` | 조건이 참이면 라벨로 점프. 조건: `c >= 6`, `lullaby`, `!lantern`, `c >= 6 & lullaby & writetruth`, `l > 2 | forgive` |
| `@jump <라벨>` | 점프 |
| `* <라벨>` | 라벨 정의. 라벨 이름은 **장 id 접두어**를 붙여 전역에서 겹치지 않게 (`ch02_lie`, `c08_good`) |
| `@next <장id>` | 이 장을 마치고 다음 장으로 (장 이동 연출 + 자동 저장 지점) |
| `@end <엔딩id>` | 엔딩. 엔딩 카드 → 크레딧(굿/트루) → 타이틀로 |

### 선택지
```
@choice
- 받아친다. => ch01_retort | c+1
- 사무적으로 무시한다. => ch01_ignore
- ?true_unlocked 내 이름을 찾으러 간다. => t06
```
- `- 문구 => 라벨 | 효과, 효과` — 효과: `c+1`, `l+1`, `c-1`, `플래그이름`(참으로 설정). 효과는 생략 가능.
- 문구 앞 `?조건 ` 을 붙이면 조건이 참일 때만 보인다.
- 선택 뒤 흐름은 각 라벨에서 이어지고, 보통 `@jump`로 공통 지점에 합류한다.

### 편지 예시
```
@letter 제412통
|이름을 잃은 별에게.
|오늘은 네가 웃는 걸 봤다. 성서관 서쪽 창, 세 번째 칸. 누가 뭘 흘렸는지 네가 고개를 숙이고 웃었어.
|네 웃음은 여전히 왼쪽 입꼬리가 먼저 올라가더라.
|— 보내지 않을 편지를, 오늘도.
@endletter
```

## 3. 문체 가이드 — 가장 중요

**목표: 한국 라이트 노벨/웹소설 상위권의 흡입력 + 순문학에 가까운 문장의 결.** 읽는 사람이 다음 줄을 누르지 않고는 못 배기게.

1. **1인칭 에스텔.** 담담하고 정확한 문장. 감정을 이름 붙여 말하지 않고, 감각과 행동으로 보여 준다. ("슬펐다" ✗ → "펜촉이 종이에 닿지 않았다. 세 번." ✓)
2. **건조한 유머.** 에스텔은 속으로 말이 많다. 숫자를 센다. 남의 문장을 교정한다. 긴장된 장면 사이에 한 줄씩 웃긴다.
3. **리듬.** 긴 문장 두세 개 뒤엔 짧은 문장 하나로 끊는다. 결정적 한 줄은 혼자 둔다.
4. **대사는 캐릭터의 말투를 지킨다** (바이블 2절). 설명조 대사 금지. 세계관 설명은 사건과 감정 속에 녹인다. 설명이 꼭 필요하면 그레고르나 루시엔의 입을 빌리되 짧게, 이미지로.
5. **감각의 고정 이미지(모티프)를 반복·변주한다:** 성묵의 은빛과 서늘함, 흰 월하화, 휘파람, 손목의 은빛 고리, 촛불, 첫눈, 새 공책의 첫 장, 찻잔 두 개, 계단 수 세기, 이름이 소리 나지 않는 입술.
6. **연출 명령을 적극적으로.** 장면 전환마다 `@bg`, `@place`, `@bgm`. 감정의 정점엔 `@wait`, `@bgm stop`, `@flash`, 빈 줄 같은 침묵(`……` 한 줄). 절정 직전엔 음악을 끊는다. 한 장에 CG는 바이블이 지정한 것을 반드시 쓴다.
7. **NVL 모드**는 긴 독백, 회상, 고백에 쓴다(한 장에 1~2번). NVL에선 한 줄이 조금 길어도 된다(200자 이내). 한 쪽에 6~9줄 쌓이면 `@clear`.
8. 클리셰는 비틀어서. 로맨스의 설렘은 과장된 표현보다 **작은 행동**(털목도리, 먼저 따라 둔 차, 계단 한 칸 아래에서 기다리는 사람)에서.
9. 금지: 영어 남발, 현대 속어, "~인 것이다" 반복, 같은 문장 구조 연속, 이모지, 과한 의성어. 맞춤법 정확히.
10. 각 장 마지막 줄은 **다음을 누르게 만드는 문장**.

## 4. 문체 샘플 (톤 기준. 그대로 베끼지 말 것)

```
@bg tower fade 1500
@place 루멘하임 · 침묵탑
@bgm tower
@se step
침묵탑의 계단은 이백열세 개였다.
세려고 센 것은 아니다. 나는 무언가를 세지 않으면 무서워지는 사람이고, 무서울 일이 있으면 계단은 대개 길다.
이백열, 이백열하나.
이백열둘에서 발을 헛디뎠다. 성묵 병이 품 안에서 찰랑였다. 깨지지 않았다. 다행이었다. 오늘 나는 한 사람의 일생을 쓰러 가는 길이고, 그 첫 문장을 잉크 없이 시작할 수는 없었다.
@show theo normal right
테오: 필경사 누님이세요? 아, 아니, 필경사님. 죄송합니다. 단장님이… 아니, 죄수가 기다리고 있습니다.
에스텔: 정정할게요. 죄수는 기다리지 않아요. 갇혀 있을 뿐이죠.
소년 간수가 입을 벌렸다가 다물었다. 나는 이런 표정을 자주 본다. 대개 나와 대화한 사람들이 짓는다.
@hide theo
@se door
```
