# 아트 디렉션 — 「이름을 잃은 별에게」

모든 그림은 코드로 그린 **SVG**입니다. 외부 이미지 파일은 쓰지 않습니다.

## 1. 한 줄 콘셉트
**"달빛 아래의 채색 필사본 × 극장판 애니메이션 배경화."** 깊은 남색 밤, 은빛 별빛, 성묵(별가루 잉크)의 푸른 은광, 촛불의 금빛. 평면 도형을 겹겹이 쌓고 부드러운 그라데이션과 대기 원근(멀수록 옅고 푸르게)으로 깊이를 만든다. 외곽선 만화체, 도트, 3D 흉내, 사진풍은 금지.

## 3. 세계의 시각 모티프
- **천환(天環)**: 하늘을 가로지르는 은빛 별의 띠. 수천 개의 작은 점(별)이 촘촘히 모인 비스듬한 호. 밤 바깥 장면의 하늘에는 거의 항상 보인다. 띠 가장자리는 부드럽게 흐려지고, 띠 안쪽엔 더 밝은 별 몇 개가 반짝인다.
- **성묵 글자**: 푸르게 빛나는 필기체 획. 한글 자모나 알 수 없는 고대 문자처럼 보이는 곡선. 금서고, 천명록의 방, 무명해에서 떠다닌다.
- **월하화**: 달빛에만 피는 흰 꽃(여섯 장 꽃잎, 백합과 목련 사이). 백색 정원, 회상.
- **은빛 고리**: 손목의 가느다란 은빛 원. 서약의 상징.
- **성서관**: 흰 대리석의 첨탑형 도서관. 끝없이 높은 서가, 아치, 둥근 창, 돔 천장.
- **루멘하임**: 청회색 지붕과 뾰족 첨탑이 층층이 쌓인 언덕 도시. 운하와 돌다리.

## 4. 기술 규칙 (반드시 지킬 것)
1. 각 그림은 **SVG 마크업 문자열**을 돌려주는 TypeScript 모듈로 만든다. React 컴포넌트가 아니다. 엔진이 `innerHTML`로 넣는다.
2. 캔버스: 배경·CG는 `viewBox="0 0 1600 900"`에 `preserveAspectRatio="xMidYMid slice"`. 휴대폰 세로 화면에선 **가운데 약 506×900만 보인다** — 핵심 피사체는 가운데 폭 500 안에 두고, 좌우는 확장 영역으로 그린다. 화면 **아래 30%는 대사창이 덮으므로** 그곳에 중요한 것을 두지 않는다.
3. **id 충돌 금지**: 한 화면에 SVG 여러 개(배경 2장 교차, CG, 스탠딩 3명)가 동시에 들어간다. 모든 `id`(gradient, filter, clipPath, mask, symbol)와 `<style>` 클래스 이름 앞에 **그림 고유 접두어**를 붙인다. 예: `archive-sky`, `cg-oath-glow`, `ch-cassian-hair`.
4. **애니메이션**: SVG 안 `<style>`의 CSS `@keyframes`로 `opacity`와 `transform`만 움직인다(반짝이는 별, 흔들리는 촛불, 떠다니는 글자, 흐르는 물빛). 그림 하나에 움직이는 요소 40개 이하. `transform-box: fill-box; transform-origin: center;`을 쓰면 편하다. `@media (prefers-reduced-motion: reduce)`에서는 애니메이션을 끈다. SMIL(`<animate>`)은 쓰지 않는다.
5. **성능**: `feGaussianBlur` 등 필터는 그림당 2개 이하, 움직이는 요소에는 필터를 걸지 않는다. 빛번짐은 `radialGradient`(가운데 불투명 → 가장자리 투명)로 만든다. 문자열 크기는 배경·CG 하나당 40KB 이하, 인물 하나(모든 표정 포함 함수)당 결과 30KB 이하.
6. 반복 요소(별, 책, 창문, 풀, 눈송이)는 코드로 생성해도 된다. 무작위는 **시드 고정 난수**(예: mulberry32)로 — 실행할 때마다 같은 그림이 나와야 한다.
7. 텍스트(`<text>`)는 쓰지 않는다(글꼴 의존). 글자처럼 보이는 것은 `path`로 그린다.
8. 입자 효과(눈, 비, 유성, 꽃잎, 등불, 먼지)는 엔진이 캔버스로 얹는다. 그림에는 그 장면의 **정적인 분위기**와 잔잔한 움직임만.

## 5. 인물 (스탠딩)
- 화풍: **역광의 명암 초상**. 인물 대부분은 깊은 그림자 톤(남색~보라 그라데이션)이고, 한쪽 가장자리를 캐릭터 고유색의 **테두리광(rim light)**이 따라간다. 얼굴은 반쯤 빛을 받아 광대, 콧날, 턱선, 눈의 빛(하이라이트)이 보인다. 머리카락은 가닥 결 몇 줄의 하이라이트. 실루엣만으로 누군지 알 수 있을 만큼 형태가 분명해야 한다.
- 캔버스: `viewBox="0 0 600 1000"`, 머리부터 허벅지 중간까지(아랫단은 화면 밖으로 잘린다고 생각하고 그라데이션으로 사라지게). 머리 꼭대기는 y≈60~120. 몸은 약간 **화면 왼쪽(관객 기준)을 향하는 3/4 자세**로 통일 — 엔진이 오른쪽 배치 때 좌우 반전한다.
- 표정 10종: `normal smile sad angry surprise serious tender pain smirk cry` — 눈(눈꺼풀 모양, 동공 크기, 하이라이트), 눈썹, 입 선, 볼 홍조, 눈물로 구분. 표정 사이에 몸은 같고 얼굴만 바뀐다.
