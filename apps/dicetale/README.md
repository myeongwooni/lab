# 다이스테일

d20을 굴려 이야기를 풀어 가는 도트 그래픽 TRPG입니다. 제1화 「꺼진 새벽 등불」에서는
새끼 용이 훔쳐 간 마을의 등불을 되찾으러 갑니다.

- 전사, 도적, 마법사, 음유시인 중 하나를 고르고 4d6(낮은 눈 하나 버림)으로 힘·민첩·지능·매력을 굴립니다
- 행동마다 게임 마스터가 판정을 요구합니다. d20 + 능력 보정이 난이도(DC) 이상이면 성공, 20은 대성공, 1은 대실패입니다
- 앞에서 알아낸 단서가 있으면 뒤의 판정을 유리하게(주사위 두 개 중 높은 눈) 굴립니다
- 전투는 차례제입니다. 공격, 직업 기술(전투마다 한 번), 물약, 도망 중에 고릅니다
- 엔딩은 넷입니다. 본 엔딩은 엔딩 도감에 남습니다
- 쓰러지면 그 장면의 처음부터 다시 할 수 있습니다
- 장면에 들어설 때마다 브라우저 `localStorage`에 저장하고, 처음 화면에서 이어하기로 돌아옵니다
- 로그인과 서버 저장 없음

모든 그림은 `app/game/sprites.ts`의 글자 격자와 `app/game/scenes.ts`의 층 목록으로 그린 SVG입니다.
한 글자가 한 도트이고, 글자와 색의 대응은 `app/game/palette.ts`에 있습니다.

## 로컬 실행

```bash
npm install
npm run dicetale
```

환경변수는 필요하지 않습니다.
