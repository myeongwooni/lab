# 천 번째 새벽, 당신에게

*To You, on the Thousandth Dawn* — 사망 회귀 판타지 로맨스 비주얼 노벨입니다.

> 죽을 때마다 되돌아가는 응급실 간호사는, 자기를 이 세계로 부른 사람이 천 번째 새벽을 기다리는 미래의 그라는 것을 알게 된다.

새벽 4시 44분, 아홉 살 환자를 떠나보낸 응급실 간호사 한서하는 병원 옥상에서 하늘로 떨어지는 모래를 봅니다.
눈을 뜨면 이세계의 왕도 솔레인, 새벽제 첫날 아침. 왼손바닥에는 금빛 모래시계 문양이 있고, 그녀는 죽을 때마다
그 아침으로 되돌아갑니다. 되돌아온다는 것을 누구에게 말하면, 들은 사람이 모래가 되어 부서집니다.
이레 뒤 새벽, 해가 잿빛으로 떠오르기 전에 — 그녀는 몇 번을 죽어야 할까요.

## 구성

- 프롤로그와 공통 루트 5장, 그 뒤로 네 갈래
  - **엘리오스 루트** 3장 — 굿 「새벽을 부르는 이름」, 배드 「재의 왕관」
  - **라젤 루트** 3장 — 굿 「늑대의 귀향」, 배드 「마지막 모래 한 알」
  - **시안 루트** 3장 — 굿 「지금에 머무는 법」, 배드 「모래 속의 누이」
  - **진실 루트** 4장 — 트루 「천 번째 새벽, 당신에게」, 어나더 「4시 44분의 옥상」. 세 사람의 굿 엔딩을 모두 본 뒤 5장 마지막 갈림길에 열립니다
- 공통 루트의 배드 「모래의 방」과 노멀 「혼자 맞는 새벽」까지 **엔딩 열 개**
- 선택지가 세 사람의 호감도와 플래그를 움직이고, 루트의 끝은 그것으로 갈립니다. 호감도와 플래그는 되감아도 남습니다
- 장마다 「재의 기록」(진실 루트는 「서하의 기록」) 한 장으로 시작합니다. 읽은 기록은 기록함에 모입니다

## 죽음과 되감기

- **사망 연출**: 화면이 핏빛으로 식었다가 꺼지고, 심장 소리가 느려지다 멎고, 화면에 금이 간 뒤 사망 카드가 뜹니다
- **되감기 연출**: 금빛 모래가 위로 쏟아지고 거대한 시계가 거꾸로 돌고, 하얗게 바랜 뒤 "제 N회차"
- **사망 기록**: 이야기 속 죽음 19가지를 모으는 도감. 잠긴 칸에는 힌트가, 연 칸에는 제목·장·묘비명이 적힙니다. 틀린 선택이 부르는 죽음도 있습니다 — 죽어서 알게 된 것은 다음 회차의 새 선택지가 됩니다
- 회차는 날짜 카드("새벽제 제 n일 · 제 N회차")와 저장 슬롯에 함께 표시됩니다

## 기능

- 대사창(ADV)과 소설식 전면 화면(NVL), 한 글자씩 풀리는 문장, 루비(윗글자)
- 자동 진행, 읽은 문장 넘기기(Ctrl), 대사 기록, 창 숨기기, 번호 키로 선택지 고르기
- 저장 슬롯 18개(장·날짜·회차·시각 표시)와 자동·빠른 기록. 선택지·장 전환·되감기·탭 닫기 때마다 자동 기록
- 특별 수록: 회상록(CG 25장), 엔딩 도감, 사망 기록, 음악실, 기록함, 장 고르기
- 배경 전환 `cross` `fade` `white` `cut`, 그리고 그림이 금빛 모래로 흩어지는 `sand`
- 글자 속도·자동 대기·글자 크기·음량 설정
- 모든 기록은 브라우저 `localStorage`(`sandglass:` 접두어)에 남습니다. 로그인과 서버 저장은 없습니다

## 그림: 코드로 그린 SVG + 그림 슬롯

지금은 외부 이미지·오디오 파일 없이 돌아갑니다.

- **그림**: 배경 33장, CG 25장, 인물 10명(표정 10종)을 코드로 그린 SVG — `app/art/`
- **음악**: 배경음악 16곡, 환경음 7종, 효과음 25종을 Web Audio API로 그 자리에서 합성 — `app/audio/`
- **입자**: 모래, 재, 불씨, 비, 등불, 먼지, 불꽃, 꽃잎, 별, 낙엽은 캔버스로 — `app/ui/Particles.tsx`

**그림 슬롯**: 일러스트 파일을 `public/art/`에 넣으면 SVG 대신 그 파일을 씁니다.

```
public/art/bg/<배경id>.webp            1920×1080
public/art/cg/<cgid>.webp              1920×1080
public/art/char/<인물id>/<표정>.webp   1200×2000, 투명 배경 (표정이 없으면 normal, 그것도 없으면 SVG)
```

`npm run dev`·`npm run build`가 먼저 `scripts/art-manifest.mjs`를 돌려 있는 파일 목록(`app/art/slots.generated.ts`)을 새로 씁니다.
슬롯마다의 경로·크기·구도·이미지 생성 프롬프트는 [`docs/art-slots.md`](docs/art-slots.md)에 있습니다.

## 원고

`app/story/<장>.ts`에 장마다 한 편씩 있습니다. 한 줄이 클릭 한 번이고, `@`로 시작하는 줄이 연출 명령입니다(`@death`, `@rewind`, `@day` 포함).

- 세계관·인물·줄거리·변수·사망 표: [`docs/bible.md`](docs/bible.md)
- 원고 규격과 문체 가이드: [`docs/script-spec.md`](docs/script-spec.md)
- 아트 디렉션: [`docs/art-direction.md`](docs/art-direction.md)

원고를 고친 뒤에는 두 가지로 확인합니다.

```bash
cd apps/sandglass
node scripts/check-story.ts                                   # 규격 위반, 없는 id·라벨, 오타 난 변수
node --import ./scripts/ts-resolve.mjs scripts/playtest.ts   # 무작위로 수백 번 끝까지 읽어 막다른 길 찾기
```

개발 서버에서는 브라우저 콘솔에 `window.__sandglassTest(원고, { loop: 3 })`로 임시 원고를 바로 읽어 볼 수 있습니다(배포판에는 없음).
