# 스크립트 규격 (SandScript) + 문체 가이드

게임 원고는 `apps/sandglass/app/story/<id>.ts` 파일 하나에 한 장(章)씩 쓴다. 파일 형식:

```ts
// 제1장 「첫 번째 새벽」
export default String.raw`
* ch01
@bgm solein
...
`;
```

- 반드시 `String.raw` 템플릿 문자열. 본문에 백틱(`)과 `${`를 쓰지 말 것.
- 파일의 첫 라벨은 장 id와 같다 (`* ch01`).
- 장의 끝은 `@next <다음 장 id>`, `@end <엔딩 id>`, `@rewind <라벨>`, `@jump`, 또는 분기(`@choice`)로 끝난다. 흐름이 끊긴 채 끝나면 안 된다.
- **모든 흐름의 끝을 확인할 것**: 라벨로 갈라진 뒤 `@jump`로 합류하지 않고 다음 라벨로 "흘러 들어가는" 실수를 하지 말 것(라벨은 벽이 아니다. 라벨 위의 명령이 끝나면 아래로 그대로 이어진다).

## 1. 한 줄 = 한 명령

빈 줄은 무시. `//`로 시작하는 줄은 주석.

### 텍스트 줄 (클릭 한 번에 한 줄)
| 형식 | 의미 |
|---|---|
| `그냥 문장.` | 서술(서하의 1인칭). 이름표 없음. |
| `엘리오스: 대사` | 대사. 화면에 “ ”가 자동으로 붙으니 **따옴표를 쓰지 말 것.** |
| `엘리오스[smile]: 대사` | 대사 + 그 인물 스탠딩의 표정을 바꿈. |
| `서하: 대사` | 주인공의 말. |
| `???: 대사` | 정체 불명의 화자. |
| `마르타: 대사` | 스탠딩이 없는 단역도 이름만 쓰면 된다. |
| `(시안): 속삭임` | 괄호 이름 = 작은 목소리/멀리서 들리는 소리. 이탤릭 처리. |

- 서술 줄에 `짧은말: 내용`처럼 앞쪽 12자 안에 쌍점(:)을 쓰면 대사로 읽힌다. **서술에는 쌍점을 쓰지 말 것.** (시각 "4시 44분"은 한글로. "04:44" 금지.)
- 한 줄은 **한국어 기준 대략 120자 이하** (ADV 대사창 3줄 분량). 긴 서술은 여러 줄로 나눈다.
- 인라인 표기:
  - `[회명|灰明]` → 루비(윗글자). 한 장에 새 용어가 처음 나올 때만. 남발 금지.
  - `*강조*` → 강조(금빛 글씨).
  - `{w}` → 타자 중간에 잠깐 멈춤. 한 줄에 1~2개까지.
  - `──` 는 그대로 표시된다(모래로 막힌 말 연출에 사용: `서하: 나 죽었다가──`).

### 무대 명령
| 명령 | 의미 |
|---|---|
| `@bg <배경id> [전환] [ms]` | 배경 교체. 전환: `cross`(기본) `fade`(검은색 경유) `white`(흰색 경유) `cut`(즉시) `sand`(모래로 흩어지듯) |
| `@cg <cgid>` / `@cg off` | 이벤트 CG 표시(회상록 해금) / 닫기. CG가 떠 있는 동안 스탠딩은 가려진다. |
| `@show <인물id> [표정] [위치]` | 스탠딩 등장/갱신. 위치: `left` `center` `right` (기본 center) |
| `@hide <인물id>` / `@hide all` | 스탠딩 퇴장 |
| `@bgm <곡id> [ms]` / `@bgm stop [ms]` | 배경음악(교차 페이드) |
| `@amb <환경음id>` / `@amb none` | 환경음 루프 |
| `@se <효과음id>` | 효과음 |
| `@fx <입자id>` / `@fx none` | 화면 입자 효과 |
| `@filter <필터id>` / `@filter none` | 화면 색조. `memory`(회상) `night`(푸른 밤) `dark`(어둡게) `blur`(흐림) `warm`(따뜻하게) `red`(핏빛, 죽음 직전) `gray`(잿빛, 회명) |
| `@shake` / `@shake big` | 화면 흔들림 |
| `@flash` / `@flash red` / `@flash gold` | 번쩍임(기본 흰색) |
| `@wait <ms>` | 멈춤 |
| `@title <작은글>|<큰글>` | 장 제목 카드. 예: `@title 제1장|첫 번째 새벽` |
| `@day <n>` | 날짜 카드 "새벽제 제 n일" + 작은 글씨로 현재 회차. 하루가 시작될 때 쓴다. |
| `@place <장소 이름>` | 장소 자막(좌상단에 잠깐). 예: `@place 솔레인 · 태양의 분수 광장` |
| `@letter <머리글>` … `@endletter` | 기록 카드(재의 기록/서하의 기록). 사이의 줄은 `|`로 시작. 한 `|`줄이 한 문단. |
| `@nvl` / `@adv` | NVL 모드(화면 전체에 문장이 쌓이는 소설식) / 일반 대사창 모드 |
| `@clear` | NVL 화면 비우기(쪽 넘김) |
| `@set <변수> <값>` / `@add <변수> <n>` / `@flag <이름>` | 변수 조작. `@add e 1`, `@flag know_sand` |
| `@if <조건> -> <라벨>` | 조건이 참이면 라벨로 점프. 조건: `e >= 6`, `know_sand`, `!ribbon`, `e >= 8 & e_waltz & e_journal`, `r > 2 | r_half` |
| `@jump <라벨>` | 점프 |
| `* <라벨>` | 라벨 정의. 라벨 이름은 **장 id 접두어**를 붙여 전역에서 겹치지 않게 (`ch02_loop4`, `e08_good`) |
| `@next <장id>` | 이 장을 마치고 다음 장으로 (장 이동 연출 + 자동 저장 지점) |
| `@end <엔딩id>` | 엔딩. 엔딩 카드 → 크레딧(GOOD/TRUE/ANOTHER) → 타이틀로 |
| **`@death <사망id>`** | **사망 연출.** 화면이 붉게 식고 심장 소리가 멎고 금이 가며, 사망 카드(사망 기록 제목)가 뜬다. 사망 기록 도감이 해금된다. 연출 뒤 다음 줄로 이어진다(보통 틈새의 방 장면). 스탠딩·CG·필터·입자는 자동으로 치워진다. |
| **`@rewind <라벨>`** | **되감기 연출.** 모래가 위로 흐르고 시계가 거꾸로 돌며 화면이 하얗게 된 뒤, 회차(`loop`)를 1 올리고 "제 n회차" 카드를 띄우고 라벨로 이동한다. 라벨은 다른 장에 있어도 된다(장 id를 라벨로 써도 된다: `@rewind ch02`). 무대(배경·스탠딩·음악·필터)는 비워진다 — 되감은 뒤 첫 장면에서 `@bg`·`@bgm`을 다시 쓸 것. 자동 저장 지점. |

### 선택지
```
@choice
- 꿰매 줄게요. 바늘이랑 독한 술 있어요? => ch01_stitch | r+1, r_stitch
- 모른 척 스튜만 먹는다. => ch01_ignore
- ?know_chapel 토비를 먼저 붙잡는다. => ch02_grab
```
- `- 문구 => 라벨 | 효과, 효과` — 효과: `e+1`, `r+1`, `s-1`, `플래그이름`(참으로 설정). 효과는 생략 가능.
- 문구 앞 `?조건 ` 을 붙이면 조건이 참일 때만 보인다. (조건 안에 공백을 넣지 말 것: `?e>=3`, `?know_chapel&e>=2`처럼 붙여 쓴다.)
- **죽음으로 이어지는 선택지**는 문구만 봐서는 티 나지 않게(하지만 돌아보면 "그랬구나" 싶게).
- 선택 뒤 흐름은 각 라벨에서 이어지고, 보통 `@jump`로 공통 지점에 합류한다.

### 선택 사망 패턴 (예시)
```
* ch02_plan
@choice
- 라젤에게 간다. => ch02_razel
- 예배당에 혼자 먼저 가 본다. => ch02_alone
* ch02_alone
@bg chapel fade
... (20~50줄)
@death d_alone
@bg between white 1500
@bgm between
@fx sand
@show ashking normal center
재의 왕: 혼자서는 안 된다. 너도 알잖나.
@rewind ch02_plan_back
* ch02_plan_back
@bg plaza cut
@bgm solein
나는 다시 광장에 서 있었다. 이번엔 망설이지 않았다.
@jump ch02_plan
```

### 기록 카드 예시
```
@letter 재의 기록 · 제 37회
|토비에게 말했다.
|토비가 모래가 되었다.
|다시는 말하지 않는다.
@endletter
```

## 3. 문체 가이드 — 가장 중요

**목표: 한국 라이트 노벨/웹소설 최상위권의 흡입력 + 순문학에 가까운 문장의 결.** 읽는 사람이 다음 줄을 누르지 않고는 못 배기게. Re:Zero의 절망과 반전, 오토메 게임의 설렘, 좋은 장르소설의 속도.

1. **1인칭 서하.** 담담하고 정확한 문장, 현대 한국 여성의 감각과 비유(편의점, 지하철, 야간근무, 커피, 을지로). 감정을 이름 붙여 말하지 않고 몸과 행동으로 보여 준다. ("무서웠다" ✗ → "맥박을 셌다. 백사십. 내 것이었다." ✓)
2. **의료인의 눈.** 동공, 호흡수, 피부색, 출혈량, 맥박. 사람을 보면 먼저 상태를 본다. 그 습관이 공포 속에서 그녀를 붙잡는다. 전문용어는 쉽게, 짧게.
3. **블랙 유머.** 서하는 속으로 말이 많다. 죽음 직후에도 한 줄씩 웃긴다(그게 그녀의 방어기제다). 단, 사망의 순간 자체에는 농담하지 않는다.
4. **죽음 장면은 짧고 강렬하게.** 감각 두세 개(온도, 소리가 멀어짐, 숫자가 끊김). 피와 상처의 구체 묘사는 절제한다. 죽음 뒤의 공허를 길게.
5. **리듬.** 긴 문장 두세 개 뒤엔 짧은 문장 하나로 끊는다. 결정적 한 줄은 혼자 둔다.
6. **대사는 캐릭터의 말투를 지킨다** (바이블 2절). 설명조 대사 금지. 세계관 설명은 사건과 감정 속에 녹인다.
7. **반복과 변주(루프물의 핵심).** 같은 장면이 되풀이될 때 같은 대사를 그대로 다시 들려주고(리리의 "서하 님! 도련님이 손님을…"), 서하의 반응만 달라지게. 되풀이될수록 서술은 압축하고("세 번째로 들은 인사였다."), 달라지는 한 줄에 힘을 준다.
8. **모티프:** 모래시계, 맥박 세기, 휴대폰 12%, 종소리 여덟 번, 흰 머리 가닥, 시계의 째깍임, 캔커피, "우선순위부터", 4시 44분, 등불, 흰 리본, 초침(고양이).
9. **연출 명령을 적극적으로.** 장면 전환마다 `@bg`, `@place`, `@bgm`. 감정의 정점엔 `@wait`, `@bgm stop`, `@flash`, 침묵(`……` 한 줄). 절정 직전엔 음악을 끊는다. 바이블이 지정한 CG는 반드시 쓴다.
10. **NVL 모드**는 긴 독백, 회상, 고백, 몽타주에 쓴다(한 장에 1~3번). NVL에선 한 줄이 조금 길어도 된다(200자 이내). 한 쪽에 6~9줄 쌓이면 `@clear`. 끝나면 `@adv`.
11. 클리셰는 비틀어서. 설렘은 과장된 표현보다 **작은 행동**(먼저 따라 둔 차, 계단 한 칸 아래에서 기다리는 사람, 태엽을 감아 주는 손).
12. 금지: 영어 남발, 과한 인터넷 속어, "~인 것이다" 반복, 같은 문장 구조 연속, 이모지, 과한 의성어. 맞춤법 정확히. 실존 작품 이름·인물 언급 금지(Re:Zero 등).
13. 각 장 마지막 줄은 **다음을 누르게 만드는 문장**.
