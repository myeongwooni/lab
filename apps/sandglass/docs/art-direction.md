# 아트 디렉션 — 「천 번째 새벽, 당신에게」

그림은 두 겹이다.

1. **그림 슬롯(최종 그림)**: `public/art/` 아래에 이미지 파일(webp/png/jpg)을 넣으면 엔진이 그것을 쓴다. 슬롯 목록과 이미지 생성용 프롬프트는 [`art-slots.md`](art-slots.md)에 있다.
2. **임시 그림(SVG)**: 파일이 없는 슬롯은 코드로 그린 SVG가 대신 나온다 — `app/art/`. 임시라도 **게임이 그것만으로 완성돼 보여야 한다.**

## 1. 한 줄 콘셉트
**"TV 애니메이션 판타지(이세계물) 극장판의 배경미술 × 셀 셰이딩 캐릭터."** 밝고 투명한 낮의 하늘과 주황 기와의 도시, 대비되는 잿빛 새벽과 금빛 모래. 선명한 색면, 부드러운 공기 원근, 역광의 빛번짐(블룸). 인물은 **또렷한 선(짙은 색 외곽선)과 2~3단 셀 음영**, 큰 눈과 눈동자의 여러 겹 하이라이트, 머리카락의 광택 띠 — 일본 TV 애니메이션의 캐릭터 설정화 느낌.

## 3. 세계의 시각 모티프
- **모래시계**: 금빛 테두리, 두 개의 유리 방울, 거꾸로 흐르는 모래. 서하의 왼손바닥 문양(가느다란 금빛 선), 공방의 깨진 역시계.
- **여명탑**: 솔레인 어디서든 보이는 거대한 시계탑. 흰 돌, 금빛 문자판(로마 숫자 대신 해와 달의 기호), 꼭대기에 제단.
- **시계들**: 시계의 집의 모든 벽. 벽시계, 탁상시계, 뻐꾸기시계, 해부된 톱니.
- **잿빛 새벽**: 해가 회색 원반으로 뜨고 하늘이 탁한 잿빛. 재가 눈처럼 내린다.
- **틈새의 방**: 검회색 재의 왕좌, 바닥에 흩어진 부서진 시계 문자판, 공중에 멈춘 톱니, **위로 떨어지는 금빛 모래**, 큰 아치 창밖의 끝없는 잿빛 새벽.
- **솔레인**: 언덕을 따라 층층이 쌓인 흰 벽과 주황 기와, 운하와 돌다리, 종탑, 천막 시장.

## 4. 임시 SVG 기술 규칙 (반드시 지킬 것)
1. 각 그림은 **SVG 마크업 문자열**을 돌려주는 TypeScript 모듈로 만든다. React 컴포넌트가 아니다. 엔진이 `innerHTML`로 넣는다.
2. 캔버스: 배경·CG는 `viewBox="0 0 1600 900"`에 `preserveAspectRatio="xMidYMid slice"`. 휴대폰 세로 화면에선 **가운데 약 506×900만 보인다** — 핵심 피사체는 가운데 폭 500 안에. 화면 **아래 30%는 대사창이 덮으므로** 중요한 것을 두지 않는다(CG는 예외로 아래까지 써도 된다 — CG가 뜨면 대사창이 반투명해진다).
3. **id 충돌 금지**: 한 화면에 SVG 여러 개가 동시에 들어간다. 모든 `id`(gradient, filter, clipPath, mask, symbol)와 `<style>` 클래스 이름 앞에 **그림 고유 접두어**. 예: `plaza-sky`, `cg-fall-glow`, `ch-elios-smile-hair`.
4. **애니메이션**: SVG 안 `<style>`의 CSS `@keyframes`로 `opacity`와 `transform`만(반짝임, 흔들리는 촛불, 흐르는 모래, 시계 초침). 그림 하나에 움직이는 요소 40개 이하. `transform-box: fill-box; transform-origin: center;`. `@media (prefers-reduced-motion: reduce)`에서 끈다. SMIL(`<animate>`) 금지.
5. **성능**: 필터(`feGaussianBlur` 등)는 그림당 2개 이하, 움직이는 요소엔 필터 금지. 빛번짐은 `radialGradient`로. 문자열 크기는 배경·CG 하나당 45KB 이하, 인물 하나(모든 표정) 결과 30KB 이하.
6. 반복 요소는 코드로 생성해도 된다. 무작위는 **시드 고정 난수**(mulberry32 등).
7. `<text>` 금지(글꼴 의존). 글자처럼 보이는 것은 `path`로.
8. 입자 효과(모래, 재, 불씨, 비, 등불, 먼지, 불꽃, 꽃잎, 별, 낙엽)는 엔진이 캔버스로 얹는다. 그림에는 **정적인 분위기**와 잔잔한 움직임만.

## 5. 인물 (스탠딩)
- 화풍: **애니메이션 셀 셰이딩 설정화.** 짙은 외곽선(검정이 아니라 각 색의 가장 어두운 톤, 두께 2~3), 피부·머리·옷마다 밝은 면/그림자 면 2단(+머리카락 광택 띠, 볼 홍조). 눈은 크고, 홍채에 그라데이션과 동공, 하이라이트 2개(큰 것 위, 작은 것 아래). 속눈썹 윗선 굵게. 코는 작은 선이나 그림자 한 점, 입은 작게.
- 캔버스: `viewBox="0 0 600 1000"`, 머리부터 허벅지 중간까지(아랫단은 화면 밖으로 잘린다고 생각하고 그라데이션으로 투명하게 사라지게). 머리 꼭대기 y≈60~120. 몸은 약간 **관객 기준 왼쪽을 향하는 3/4 자세**로 통일 — 엔진이 오른쪽 배치 때 좌우 반전한다. 머리 크기는 키의 1/6.5 정도(애니 비율).
- 표정 10종: `normal smile sad angry surprise serious tender pain smirk cry` — 눈꺼풀, 동공 크기, 하이라이트, 눈썹, 입, 홍조, 눈물(글썽 / 흐름), 땀방울 등. 표정 사이에 몸은 같고 얼굴만.
