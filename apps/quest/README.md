# 오늘의 퀘스트

이름과 임무를 입력하면 파티원 중 오늘의 용사 한 명을 소환하는 가벼운 추첨기입니다.

- 로그인과 서버 저장 없음
- 브라우저의 `crypto.getRandomValues()`를 사용한 추첨
- 최근 파티원과 퀘스트는 브라우저 `localStorage`에 저장
- 결과 공유, 당첨자 제외 후 연속 추첨 지원
- 좀은 화면에서는 `의뢰서` / `원정대` 탭으로 나뉘며, 소환하면 원정대 탭으로 넘어가 스크롤 없이 결과를 보여 줍니다

## 로컬 실행

```bash
npm install
npm run quest
```

환경변수는 필요하지 않습니다.
