# 픽셀룸 — 하루 한 방, 10분의 탈출

매일 한국 시간 자정에 방의 이름·색감·책의 암호 순서·숫자가 바뀌는 단일 방 방탈출 게임입니다.
방 안의 사물을 클릭해 조사하고, 아이템을 선택해서 대상에 사용하고, 금고를 열어 출입문으로 탈출합니다.

## 플레이 방법

1. 카펫과 화분을 뒤져 필요한 아이템을 찾으세요.
2. 책장과 시계를 조사해 색상 순서와 첫 번째 숫자를 확인하세요.
3. 서랍에는 황동 열쇠, 그림에는 푸른 렌즈, 라디오에는 건전지가 필요합니다.
4. 단서의 색상 순서대로 금고에 세 자리를 입력하세요.
5. 금고의 은빛 열쇠를 선택해 출입문을 열면 탈출입니다.

모든 클릭 대상에는 키보드 포커스 및 레이블이 있습니다. `Esc`는 금고를 닫고, 금고가 열린 상태에서는 숫자/Backspace/Enter를 사용할 수 있습니다. 버튼을 눌러 단서를 표시하거나 힌트를 확인할 수 있습니다.

## 실행

루트에서 `npm install` 이후 `npm run pixelroom` (포트 3008). `npm run build --workspace apps/pixelroom`으로 빌드합니다.

## 구조

- `app/page.tsx`: 게임 로직과 반응형 화면
- `app/RoomArt.tsx`: 정적인 SVG 도트 룸과 상호작용 상태 표현
- `app/globals.css`: 스타일과 애니메이션
- `lib/game.ts`: 날짜별 결정론적 퍼즐, 상태/타입 및 시간 계산

## 데이터 및 운영

- 날짜 기준: `Asia/Seoul`, 하루에 하나의 결정론적 퍼즐 (서버 DB 불필요)
- 진행 중 타이머는 새로고침/탭 닫기를 해도 계속 진행하며 최대 10분. 재도전 가능
- 저장: 브라우저 `localStorage`에 당일 진행 상태 및 개인 최고 기록
- 공유: Web Share API 또는 클립보드로 탈출 결과를 공유. 암호는 공유되지 않음
- 미지원: 전 세계 공용 리더보드, 진짜 새로운 맵 자동 생성. 이번 MVP는 같은 맵 구도에서 매일 조명/방 이름/퍼즐이 달라집니다.
