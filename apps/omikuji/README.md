# 오늘의 냥쿠지

도트 고양이가 흔들어 주는 하루 한 번의 운세 뽑기입니다.

- 통을 흔들면 대길부터 대흉까지 일곱 등급 중 하나가 나오고, 등급마다 다른 고양이가 나타납니다
- 하루에 한 번만 뽑을 수 있고, 자정(현지 시각)이 지나면 새 쪽지가 들어옵니다
- 결과는 브라우저 `localStorage`에 시드만 저장하고, 쪽지 내용은 시드에서 다시 계산합니다
- 모은 고양이는 냥이 도감에, 연속으로 뽑은 날은 연속 일수로 남습니다
- 로그인과 서버 저장 없음

| 등급 | 고양이 | 확률 |
| --- | --- | --- |
| 대길 | 복고양이 | 8% |
| 길 | 치즈냥 | 17% |
| 중길 | 삼색냥 | 22% |
| 소길 | 턱시도냥 | 20% |
| 말길 | 고등어냥 | 18% |
| 흉 | 흰둥냥 | 12% |
| 대흉 | 까망냥 | 3% |

## 로컬 실행

```bash
npm install
npm run omikuji
```

환경변수는 필요하지 않습니다.
